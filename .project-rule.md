# ZDoc Project Directives
- **Zero Runtime Reflection Execution:** Inspect target assemblies exclusively using `MetadataLoadContext`; never execute foreign assembly code at runtime.
- **Self-Contained Output:** Always inline all CSS, JS, and SVG assets into a single standalone HTML document with zero external CDNs or HTTP dependencies.
- **Dogfooding Validation:** Validate doc comment resolution against compiler-generated XML IDs using `DocLens.SampleLib`.
